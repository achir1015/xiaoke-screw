# 小柯機器人螺絲3D產生器　開發紀錄

開發者：吳玉柱 先生 與 Claude AI Opus 5.5　｜　期間：2026-11-18（約 07:00～08:35，一個上午完成六個平台）

## 需求（使用者原話整理）

- 開發主題：小柯機器人與螺絲3D產生器工具（Screw and nut 3D generator）。
- 平台：桌面版 Windows 11、MacBook Pro；線上版（HTML）；手機版 iPhone、iPad（要有線上安裝功能）、Android。先做 Windows，再逐一完成。
- 要有更新功能；圖示是小柯機器人＋螺絲 3D 的小圖示，安裝要建立捷徑；要有語音動態教學。
- 適合在 Bambu Studio 內使用，方式和同系列的「Genstrio 3D 托盤生成器」（xiaoke-tray）一樣。
- 參考資源：
  - [kevmasajedi/123DScrew](https://github.com/kevmasajedi/123DScrew)：約 100 行的 build123d 腳本，ACME 類梯形螺紋、牙側角／牙高／牙頂平台／圓角參數、TOL 公差縮放、列印技巧
  - [scimulate/BoltGenerator](https://github.com/scimulate/BoltGenerator)、GitHub topics/screw
  - [charan-rathore/Automation-of-3D-Bolt-Dataset](https://github.com/charan-rathore/Automation-of-3D-Bolt-Dataset)：Fusion 360 批量產生公制六角螺栓（M1～M48 規格表）
  - [jbruce12000/easy-bolt](https://github.com/jbruce12000/easy-bolt)：OpenSCAD 螺栓、螺帽、墊圈、螺紋桿；需求文件附了 threadlib 與 Easy Bolt 的零件種類圖（各種頭型、起子槽、蓋形／蝶形／滾花螺帽、支柱、雙頭螺絲等）
- 資料夾內的需求文件 `Screw and nut 3D generator.docx` 可以使用。

## 關鍵決策

| 問題 | 決定 | 理由 |
|---|---|---|
| 沿用參考專案的程式嗎 | 全部自己寫，授權 MIT | 參考專案都依賴桌面 CAD（build123d、Fusion 360、OpenSCAD），不能在瀏覽器或手機上跑；自己寫才能六平台共用同一份程式，也不受 AGPL 等授權限制 |
| 幾何核心 | manifold-3d（WASM，約 0.5 MB）在 Web Worker 執行 | 布林運算穩健又快（M8 套組約 0.3 秒）；托盤用的 OpenCascade 23 MB、螺旋掃掠又慢又容易失敗 |
| 螺紋怎麼做 | 自寫「螺旋帶」網格（`src/geom/thread.ts`） | 把一個螺距內的牙型點，沿圓周每一格抬升「導程×角度比例」，整圈接回時錯開一個導程 → 牙頂、牙底都是精確平面，三角形少；兩端用軸心扇形封口後再用布林切成長度 |
| 公母牙怎麼保證鎖得進去 | 相位統一以 z = 0 為準；母牙切刀 = 同一條螺紋半徑加大「配合間隙」；螺帽放在螺距整數倍的高度 | 測試直接把組合圖裡的螺絲、墊圈、螺帽求交集，體積要是 0；錯開半個螺距就會干涉（反證） |
| 牙型 | 三角牙（ISO 68-1，5/8 H，牙頂 P/8、牙底 P/4）、梯形（ACME 類，可調牙型角／牙高／牙頂平台）、方牙、圓牙，全部可加轉角圓角 | 涵蓋標準規格，也有 123DScrew 那種平頂「列印友善大牙」 |
| 介面 | 自寫單頁：零件卡片 → 規格 → 參數表單（由宣告式 GROUPS 產生）＋ three.js 預覽 | 比 Genstrio 那種「首頁選產生器」更直接；三步驟也方便語音教學 |
| 「在 Bambu Studio 內使用」 | 和托盤生成器一樣做「送到 Bambu Studio」：產生 3MF（每個零件一個物件、已直立擺好）後用 bambu-studio 開啟 | Bambu Studio 沒有第三方外掛介面 |
| 桌面／手機外殼 | 照抄 xiaoke-tray 的 electron/、ios/、android/、src/xiaoke.ts，改名稱、協定（`xkscrew://`）、埠（iOS 48301）、資料夾（小柯螺絲） | 外殼已在托盤生成器六平台驗證過 |
| 版本 | v1.0.0 Windows → v1.1.0 加 Mac（並改由 CI 建置）→ v1.2.0 加 iPhone／iPad；Android APK 掛在 v1.2.0 | Android 只多了手機專用程式路徑 |

## 過程（依時間）

1. **讀需求**：解開 docx（文字＋兩張圖：threadlib 剖面、Easy Bolt 零件總覽），讀托盤生成器的記憶與 CLAUDE.md，決定沿用外殼、幾何自寫。
2. **建專案**：`xiaoke-screw/`，Vite＋TypeScript＋three.js＋manifold-3d＋fflate，Electron 33.4.11＋electron-builder 25.1.8，用 nvm 的 Node 22 安裝（PATH 裡的 Node 20 跑不動 vite 8）。
3. **螺紋核心**（`thread.ts`）：先寫測試再往上蓋 — M8 外螺紋體積落在小徑圓柱與大徑圓柱之間、genus 0；公母牙在螺距整數倍不干涉、錯半牙會干涉；梯形四線、圓牙、方牙都能建。第一次就全過，M8×20 只要幾十毫秒。
4. **規格表與零件**（`params.ts`、`parts.ts`、`build.ts`）：
   - 規格：ISO 粗牙 M3～M30、細牙 5 種、UNC 4 種（含相機 1/4"、腳架 3/8"）、ISO 梯形 Tr8～Tr20、T8 四線絲桿、列印大牙 6.25×2.5（123DScrew 範例）／10×3／16×4／25×5、圓牙 12×3；附六角對邊、頭高、螺帽高、內六角尺寸。
   - 螺絲頭 10 種（六角、法蘭、內六角圓柱、圓柱、沉頭、圓頭、滾花、四角、多邊形、無頭）× 起子槽 5 種（無、一字、十字、內六角、梅花）；光桿、末端倒角、中空孔、左旋。
   - 螺帽 7 種（六角、法蘭、蓋形、蝶形、滾花、四角、多邊形），30° 倒角、母牙入口倒角；墊圈；螺紋桿（全牙／雙頭／單邊牙，中段六角或光桿）；螺紋嵌件（滾花／圓／六角外形）；支柱（母－公、母－母）；套組（螺絲＋墊圈＋螺帽）。
   - 列印排版：圓頭螺絲倒過來（螺紋朝下），其他頭朝下；底面貼平台、一列排開。
   - 測試 12 項：所有頭型×起子槽 49 種、所有螺帽、所有規格的套組、5 種配合情境（M8、左旋 M10、T8 四線、列印大牙、圓牙）不干涉。
5. **畫面**：`index.html`＋`main.ts`（表單、規格、範本／分享連結、建模排程與防抖）、`viewer.ts`（Z 軸朝上、折線法線、剖面、螺帽旋入動畫：每轉一圈前進一個導程，左旋反轉）、`export.ts`（二進位 STL、3MF）、`style.css`（淺色／深色）。瀏覽器預覽調整：剖面原本切掉面向鏡頭的另一半 → 改切靠近鏡頭這半；蝶形螺帽翅膀太大 → 縮成接近實物比例。
6. **語音動態教學**：沿用托盤的引擎，重寫 15 步：選零件 → 3D 預覽 → 規格（M8→M12）→ 長度（30→45）→ 螺絲頭（內六角→滾花）→ 螺帽（蝶形）→ 螺紋（梯形大牙）→ 配合間隙 → 工具列（剖面、旋入動畫、列印排版）→ 資訊與列印技巧 → 匯出 → 送 Bambu Studio（線上／iOS／Android 各有說法）→ 範本與分享 → 更新。教學結束會還原使用者原本的設定。
7. **圖示**：`scripts/make_icon.py` 畫金色內六角螺絲＋藍色六角螺帽＋小柯機器人頭盔，同時產生 Windows ico、網頁 PNG、iOS 1024／安裝頁圖示、Android mipmap、安裝頁 QR Code。
8. **Windows v1.0.0**：NSIS 安裝版＋免安裝版；`/S` 安裝到 `%LOCALAPPDATA%\Programs\XiaokeScrew`，桌面＋開始選單捷徑。`e2e/desktop.mjs` 對已安裝版 18 項全過，包含實際送進 Bambu Studio（3MF 存到 OneDrive 的「文件\小柯螺絲」）。踩坑：NSIS 靜默安裝後會自動開 App，單一實例讓測試連不上；第一次開啟會自動播放教學，測試要等它出現再關。另外驗證 3MF 結構：螺絲、墊圈、螺帽三個物件 0 條非流形邊、底面 z = 0。
9. **公開 GitHub**：使用者同意後建立 `achir1015/xiaoke-screw`（公開、MIT），手動上傳 v1.0.0；`e2e/update-check.mjs` 確認程式內更新讀得到。
10. **Mac v1.1.0**：加 `.github/workflows/build.yml`（推 package.json 版本 → 測試 → 建 win＋mac-arm64＋mac-x64 → 發 Release）、Mac 保留 ⌘Q／複製貼上選單。CI 一次成功。Intel MacBook Pro（macOS 26.3）`scripts/mac-install-test.sh … --bambu` 18 項全過。Windows 程式內更新 1.0.0→1.1.0 實測成功（約 16 秒下載，裝完自動重開，仍在個人安裝資料夾）。
11. **線上版**：`pages.yml` 推 main 自動部署 https://achir1015.github.io/xiaoke-screw/ ；綠鈕變「下載 3MF」、左下桌面版連結；手機寬度版面改為標題→預覽→資訊→參數。線上網站實測 M10 套組約 1 秒建好、3MF 下載 486 KB、無錯誤。
12. **iPhone／iPad v1.2.0**：`ios/`（XcodeGen、WKWebView＋本機伺服器埠 48301）與 `public/ios/` 安裝頁。Mac 上用 Terminal 執行 `build-ipa.sh` 產生 Ad Hoc .ipa（0.8 MB，含 iPad 與 iPhone 兩台）；iPhone 15 Pro Max devicectl 安裝並啟動；iPhone 17 Pro Max、iPad Pro 13 模擬器截圖確認（模擬器冷啟動要十幾秒才出畫面，第二次就快）。.ipa 手動上傳 Release。之後使用者回報 iPhone／iPad 實機安裝測試完成。
13. **Android**：`android/`（無 Gradle 的 `build.py`，aapt2 遇中文路徑改在暫存資料夾建置），新金鑰 `xiaokescrew.jks`；返回鍵先關教學。三星 SM-S9380 `e2e/android.mjs` 14 項全過，截圖確認版面；正式版 APK 上傳到 v1.2.0。
14. **使用者在 GitHub 網頁兩次修改 README**（加圖片與展示連結），之後推送一律先 `git pull --rebase`。

## 已知限制與注意事項

- **Android 金鑰** `android/xiaokescrew.jks`（alias `xiaokescrew`、密碼 `android`）只在這台電腦，沒放 GitHub；遺失就無法覆蓋安裝，請備份。
- **Mac 版未公證**：第一次開啟要在「應用程式」對 App 按右鍵 →「打開」。
- **iOS .ipa 是 Ad Hoc**：只能裝在開發者帳號登記過的裝置。
- **Bambu Studio** 已開著兩個以上舊視窗時，新開的實例會卡在「正在載入配置」，關掉舊視窗即可。
- **M5 以下公制細螺紋**用 FDM 不容易印好，程式會提醒改用列印友善大牙。

## 發佈新版的步驟

1. 改 `package.json` 的 `version`，更新 `.github/release-notes.md`、`public/ios/manifest.plist` 的 bundle-version。
2. `git pull --rebase` 後推 main → `build.yml` 自動建 Windows＋Mac 並建立 Release；`pages.yml` 自動更新線上版。等待：`GITHUB_TOKEN=… node e2e/wait-ci.mjs`（線上版加 `WF=pages.yml`）。
3. iPhone／iPad：把 `package.json`、`dist`、`ios` 傳到 Mac 的 `~/Developer/xiaoke-screw` → 在 Mac 畫面上的終端機執行 `ios/build-ipa.sh` → 上傳 `xiaoke-screw-ios.ipa`（檔名固定）。
4. Android：`python android/build.py` → 上傳成 `XiaokeScrew-<版本>-android.apk`（檔名固定格式，App 內更新靠它）。
5. 沒有 gh CLI：用 `git credential fill` 取 token 打 GitHub API。
